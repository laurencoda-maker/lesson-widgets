🧠 Mémorisez

La règle à retenir

The rule to remember

Il est, elle est, ils sont, elles sont, c'est ou ce sont ? Which form should I use?

une personne, un animal, une chose one person, animal, thing deux, trois, quatre… personnes, animaux, choses two, three, four… people, animals, things
il est + nom masculin (étudiant…) + adjectif masculin (espagnol…) ils sont + nom masculin (étudiants…) + adjectif masculin (espagnols…)
elle est + nom féminin (étudiante…) + adjectif féminin (espagnole…) elles sont + nom féminin (étudiantes…) + adjectif féminin (espagnoles…)
c'est + article (le, la, un, une, mon, votre…) + nom (liste, étudiant…) + nom de personne (Léa, madame Rang…) ce sont + article (les, des, mes, vos…) + nom (listes, étudiants…) + noms de personne (Bettina et Léa…)

📘 Topo grammaire

Le verbe ÊTRE : les formes principales

How to use "be" in French

💡

À retenir : utilisez c'est / ce sont pour identifier (qui ? quoi ?). Utilisez il/elle est, ils/elles sont pour décrire quelqu'un ou donner une information sur cette personne.

Use c'est / ce sont for identification (who? what?). Use il/elle est, ils/elles sont to describe someone or give information about them.
